도면 한 장을, 끝까지 이 프로그램 안에서

넘버링 → 손상범위 표시 → 사진 정리 → 사진첩 출력까지, 정밀안전점검 결과보고서를 만들 때 반복되는 작업을 한 프로그램 안에서 끝냅니다. 아래 화면은 실제 v1.2.4를 그대로 옮긴 것입니다.

실제 화면 · 도면 한 장에 들어가는 것

1넘버링과 표기

번호만 찍는 도구가 아닙니다. 도면을 A4 규격에 앉히고, 손상 범위를 표시하고, 표제란을 채우고, PDF로 내보내는 것까지 한 프로그램 안에서 끝납니다.

작업유형
지시점 지시선 구분

선택된 버튼 아래 2px 램프가 켜집니다 — 색이 없는 도구는 앰버, 색을 가진 구분은 자기 잉크색. 화살표 · 직선 · 결함(빨강)

지시점 두 종류(화살표·점), 지시선 꺾임 네 종류(직선·ㄱ자·ㄴ자·번개), 구분 색 세 종류(결함·보수·신규) — 이 조합을 클릭 한 번으로 바꿔가며 찍습니다. 이미 찍은 번호를 선택한 채로 바꾸면 그 번호에만 그대로 적용됩니다.

그리기

2클릭 지시선, 번호는 알아서. 첫 클릭은 점검 위치, 두 번째 클릭은 번호 자리. 번호는 순서대로 자동으로 붙고, 중간 것을 지우면 다시 정렬됩니다. Q를 누르면 수평·수직으로 고정됩니다.

표기

결함·보수를 색으로 구분. 카테고리별 색을 지정하고, 화살표와 점, 꺾임 4종(직선·ㄱ자·ㄴ자·번개) 중에 고릅니다. 1F-01처럼 층별 접두어도 붙습니다.

범위

손상 범위는 해치로. 외관조사망도에 쓰는 45° 해치 도형을 사각·원형으로 그립니다. 번호를 차지하지 않아 지시선과 겹쳐 써도 됩니다.

사진

사진 폴더를 번호에 연결. 현장 사진 폴더를 열면 파일명 끝 숫자를 읽어 번호와 자동으로 짝지어 줍니다. DSC_042.jpg → 42번. 파일명을 바꿔 저장하는 것도 앱에서 합니다.

A4 도면 한 장에 지시선·번호·해치(손상 범위)·표제란까지 전부 담깁니다 — 표제란은 실제 앱과 같이 PROJECT TITLE · DRAWING NAME · SCALE 3칸입니다.

A4 6칸 격자

img-01.jpg→101.jpg 파일명 변환과 아래 경고 팝업 문구는 실제 실행 화면 그대로입니다. 완성된 사진첩 구성이 어떻게 보이는지는 아래 예시로 보여드립니다.

STEP 01

외관집계표 불러오기

기존에 쓰던 엑셀 외관집계표(.xlsx)를 그대로 불러옵니다. 층·위치·결함내용 문구를 다시 입력할 필요가 없습니다.

STEP 02

3자 대조

집계표 행, 도면 넘버링, 사진 폴더 세 가지를 자동으로 맞춰봅니다. 어긋난 항목은 바로 분류됩니다.

STEP 03

미매칭 경고

사진이 없거나 번호가 어긋난 항목은 팝업으로 미리 알려줍니다. 보고서에 낸 뒤 발견하는 누락을 미리 잡습니다.

STEP 04

PDF로 출력

A4 한 장에 6칸 격자로 배치된 사진첩이 PDF 한 개로 저장됩니다. 미리보기로 먼저 확인할 수 있습니다.

배치 순서

도면이 아니라 집계표 행 순서 그대로 배치됩니다. 층이 바뀌어도 페이지를 억지로 나누지 않습니다.

격자

A4 한 장에 6칸 고정. 사진은 칸에 맞춰 자동으로 늘려 채웁니다.

미매칭 표기

사진이 없는 번호는 "사진 없음"으로 표시되고, 생성 전 경고 팝업으로 한 번 더 확인시켜 줍니다.

문구 서식

(보수완료) / (신규) 표기를 집계표 내용대로 자동으로 붙이고, 치수가 있으면 줄바꿈 위치까지 맞춰 정리합니다.

표제 연동

도곽에서 설정한 Project Title이 사진첩 표제에도 그대로 들어갑니다. 따로 입력할 필요가 없습니다.

사진 방향

세로로 찍힌 사진도 EXIF 정보로 자동 회전해 칸에 바르게 들어갑니다.

기존 엑셀 매크로(부록. 사진첩 - 메뉴.xlsm) 방식을 대체합니다. 배치 순서·6칸 고정·PDF 단일 출력 규칙은 기존 양식과 동일하게 맞췄습니다.

✓ 실행 확인

실제 건물 도면 5개 층(지상1~5층)에 결함 9건을 찍고, 외관집계표 엑셀을 만들어 불러와 파일명 일괄변환·3자 대조·PDF 생성까지 전 과정을 직접 실행해 확인했습니다. 아래 경고 팝업은 그 실제 문구이며, 사진첩 예시는 완성 결과물의 구성을 보여드리기 위해 6칸으로 간추렸습니다.

매칭되지 않은 번호가 있습니다

사진 없음 (1건)

4F-01

사진 없는 칸은 "사진 없음"으로 표기되고, 집계표에 없는 번호는 사진첩에서 빠집니다.

칸 구성·문구 서식·"사진 없음" 표기는 실제 생성 결과와 동일합니다. 사진 5장은 매칭되고 1장(4F-01)만 현장에서 촬영을 놓친, 실제로 자주 있는 상황을 예시로 구성했습니다.

완성된 PDF 미리보기

표제란은 한 번 입력하면 PROJECT TITLE·SCALE은 전 페이지에 그대로 적용되고, DRAWING NAME만 페이지별로 따로 저장됩니다. 배치·표제란 구조·잉크 3색은 실제 출력과 동일한 구성이며, 여러 페이지를 불러오면 페이지 수만큼 PDF 한 개에 그대로 담깁니다.

출력

A4 규격 그대로 PDF

Project Title / Drawing Name / 축척을 입력한 표제란(도곽)이 도면 아래에 자동으로 배치됩니다. 열 너비·글씨 크기·표제란 높이를 직접 조정할 수 있습니다.

서랍

화면을 가리지 않는 도곽 설정

설정창이 캔버스를 덮지 않고 우측에서 서랍처럼 열립니다. 슬라이더를 조절하는 동안에도 도면이 계속 보입니다.

저장

작업 중 자동 저장

고칠 때마다 자동으로 저장되고, 프로그램을 다시 켜면 하던 작업을 이어서 엽니다.

배율

도면·넘버링 배율을 따로 조절

일반 휠은 화면 줌, Shift+휠은 넘버링·도곽 크기, Ctrl+휠은 도면 자체 크기를 조절합니다. 확대·축소를 반복해도 화질이 나빠지지 않습니다.
