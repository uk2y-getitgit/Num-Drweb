제품 소개

도면 한 장을, 끝까지 이 프로그램 안에서

넘버링 → 손상범위 표시 → 사진 정리 → 사진첩 출력까지, 정밀안전점검 결과보고서를 만들 때 반복되는 작업을 한 프로그램 안에서 끝냅니다. 아래에서 기능을 순서대로 확인하세요.

도면 한 장에 들어가는 것

1넘버링과 표기

번호만 찍는 도구가 아닙니다. 도면을 A4 규격에 앉히고, 손상 범위를 표시하고, 표제란을 채우고, PDF로 내보내는 것까지 한 프로그램 안에서 끝납니다.

그리기

2클릭 지시선, 번호는 알아서

첫 클릭은 점검 위치, 두 번째 클릭은 번호 자리. 번호는 순서대로 자동으로 붙고, 중간 것을 지우면 다시 정렬됩니다. Q를 누르면 수평·수직으로 고정됩니다.

표기

결함·보수를 색으로 구분

카테고리별 색을 지정하고, 화살표와 점, 꺾임 4종(직선·ㄱ자·ㄴ자·번개) 중에 고릅니다. 1F-01처럼 층별 접두어도 붙습니다.

범위

손상 범위는 해치로

외관조사망도에 쓰는 45° 해치 도형을 사각·원형으로 그립니다. 번호를 차지하지 않아 지시선과 겹쳐 써도 됩니다.

사진

사진 폴더를 번호에 연결

현장 사진 폴더를 열면 파일명 끝 숫자를 읽어 번호와 자동으로 짝지어 줍니다. DSC_042.jpg → 42번. 파일명을 바꿔 저장하는 것도 앱에서 합니다.

신규 기능

2사진첩 자동생성NEW · v1.2.1~

엑셀 매크로로 하나씩 채우던 사진첩을, 외관집계표와 도면 넘버링을 그대로 대조해 A4 6칸 사진첩 PDF로 한 번에 만듭니다.

STEP 01

외관집계표 불러오기

기존에 쓰던 엑셀 외관집계표(.xlsx)를 그대로 불러옵니다. 층·위치·결함내용 문구를 다시 입력할 필요가 없습니다.

STEP 02

3자 대조

집계표 행, 도면 넘버링, 사진 폴더 세 가지를 자동으로 맞춰봅니다. 어긋난 항목은 바로 분류됩니다.

STEP 03

미매칭 경고

사진이 없거나 번호가 어긋난 항목은 팝업으로 미리 알려줍니다. 보고서에 낸 뒤 발견하는 누락을 미리 잡습니다.

STEP 04

PDF로 출력

A4 한 장에 6칸 격자로 배치된 사진첩이 PDF 한 개로 저장됩니다. 미리보기로 먼저 확인할 수 있습니다.

배치 순서

도면이 아니라 집계표 행 순서 그대로 배치됩니다. 층이 바뀌어도 페이지를 억지로 나누지 않습니다.

격자

A4 한 장에 6칸 고정. 사진은 칸에 맞춰 자동으로 늘려 채웁니다.

미매칭 표기

사진이 없는 번호는 "사진 없음"으로 표시되고, 생성 전 경고 팝업으로 한 번 더 확인시켜 줍니다.

문구 서식

(보수완료) / (신규) 표기를 집계표 내용대로 자동으로 붙이고, 치수가 있으면 줄바꿈 위치까지 맞춰 정리합니다.

표제 연동

도곽에서 설정한 Project Title이 사진첩 표제에도 그대로 들어갑니다. 따로 입력할 필요가 없습니다.

사진 방향

세로로 찍힌 사진도 EXIF 정보로 자동 회전해 칸에 바르게 들어갑니다.

기존 엑셀 매크로(부록. 사진첩 - 메뉴.xlsm) 방식을 대체합니다. 배치 순서·6칸 고정·PDF 단일 출력 규칙은 기존 양식과 동일하게 맞췄습니다.

1F-01균열 (0.2x2.1)
1F-02박리 (보수완료)
1F-03누수 (신규)
1F-04사진 없음
1F-05백화현상
1F-06철근노출

마무리

3표제란과 PDF 출력

불러온 도면을 A4에 맞춰 앉히고, 표제란을 채워 PDF로 내보냅니다. 여러 장이면 여러 장 그대로 나옵니다.

출력

A4 규격 그대로 PDF

Project Title / Drawing Name / 축척을 입력한 표제란(도곽)이 도면 아래에 자동으로 배치됩니다. 열 너비·글씨 크기·표제란 높이를 직접 조정할 수 있습니다.

저장

작업 중 자동 저장

고칠 때마다 자동으로 저장되고, 프로그램을 다시 켜면 하던 작업을 이어서 엽니다.

배율

도면·넘버링 배율을 따로 조절

일반 휠은 화면 줌, Shift+휠은 넘버링·도곽 크기, Ctrl+휠은 도면 자체 크기를 조절합니다. 확대·축소를 반복해도 화질이 나빠지지 않습니다.
