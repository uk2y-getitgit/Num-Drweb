클릭 1 점검 위치 → 클릭 2 번호 자리. 직접 해보세요.

도면 한 장에 들어가는 것

1도면 한 장을 끝까지 만듭니다

번호만 찍는 도구가 아닙니다. 도면을 A4 규격에 앉히고, 손상 범위를 표시하고, 표제란을 채우고, PDF로 내보내는 것까지 한 프로그램 안에서 끝납니다.

그리기

2클릭 지시선, 번호는 알아서

첫 클릭은 점검 위치, 두 번째 클릭은 번호 자리. 번호는 순서대로 자동으로 붙고, 중간 것을 지우면 다시 정렬됩니다. Q를 누르면 수평·수직으로 고정됩니다.

표기

결함·보수를 색으로 구분

카테고리별 색을 지정하고, 화살표와 점, 꺾임 4종(직선·ㄱ자·ㄴ자·번개) 중에 고릅니다. 1F-01처럼 층별 접두어도 붙습니다.

범위

손상 범위는 해치로

외관조사망도에 쓰는 45° 해치 도형을 사각·원형으로 그립니다. 번호를 차지하지 않아 지시선과 겹쳐 써도 됩니다.

사진

사진 폴더를 번호에 연결

현장 사진 폴더를 열면 파일명 끝 숫자를 읽어 번호와 자동으로 짝지어 줍니다. DSC_042.jpg → 42번. 파일명을 바꿔 저장하는 것도 앱에서 합니다.

출력

A4 규격 그대로 PDF

불러온 도면을 A4에 맞춰 앉히고, 표제란을 채워 PDF로 내보냅니다. 여러 장이면 여러 장 그대로 나옵니다.

저장

작업 중 자동 저장

고칠 때마다 자동으로 저장되고, 프로그램을 다시 켜면 하던 작업을 이어서 엽니다. 프로젝트 파일(.numdraw)로 따로 보관할 수도 있습니다.

체험판과 정품

2먼저 써 보고 정하세요

체험판은 기간 제한이 없습니다. 도면을 몇 장이든 불러와 번호를 다 매겨 보고, 결과물이 쓸 만한지 확인한 다음에 구매하시면 됩니다.

체험판 받기

인터넷이 안 되는 현장에서도 쓸 수 있나요?

됩니다. 인증할 때 한 번만 인터넷이 필요하고, 그 뒤로는 인터넷 없이 사용합니다. 체험판은 인증이 없으므로 처음부터 끝까지 인터넷 없이 씁니다.

PC를 바꾸면 어떻게 하나요?

쓰던 PC의 등록을 반납 처리해 드리면 새 PC에서 다시 인증할 수 있습니다. 메일로 알려 주세요. 인증키는 그대로 씁니다.

사무실 PC와 현장 노트북에 같이 깔아도 되나요?

인증키 하나로 2대까지 됩니다. 3대째부터는 인증이 되지 않습니다.

Mac에서도 되나요?

지금은 Windows 10·11 64비트만 지원합니다.

사진첩(Excel) 보고서도 만들어지나요?

아직입니다. 지금은 번호와 사진을 연결하고 파일명을 정리하는 데까지 됩니다. Excel 사진첩 자동 생성은 준비 중입니다.

설치할 때 파란 경고창이 뜹니다.

코드 서명 인증서가 없어 Windows가 처음 보는 프로그램에 띄우는 경고입니다. 추가 정보 → 실행을 누르면 설치됩니다.
