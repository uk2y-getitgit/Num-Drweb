사용 가이드

실제 프로그램 화면을 그대로 옮겨왔습니다 — 버튼 위에 마우스를 올리면 그 자리에서 바로 설명이 나옵니다. 나머지 절차(설치·단축키 등)는 아래에서 이어서 확인하세요. 세부 스크린샷은 순서대로 채워 넣을 예정입니다.

실제 화면 둘러보기

다크·라이트 테마, 넘버링·사진·조절 탭을 그대로 옮겼습니다. 버튼·슬라이더 위에 마우스를 올려보세요.

키보드로도 확인할 수 있습니다 — Tab으로 버튼 사이를 이동하세요.

설치 · 실행

설치 파일을 내려받아 실행하면 설치가 진행됩니다. 별도 설정 없이 바로 실행할 수 있습니다.

지원 OSWindows 10 / 11 (64bit)
설치 방식설치형 (.exe) — 더블클릭으로 설치·실행
인터넷정품 인증 시 최초 1회만 필요, 이후 오프라인 사용 가능
권장 브라우저 기능사진 폴더 연결·파일명 일괄변경은 Chrome/Edge 계열(File System Access API)에서만 동작 — Firefox 미지원

기본 작업 순서

  1. 도면 불러오기 — PDF 또는 이미지를 드래그하거나 파일 선택으로 불러옵니다.
  2. 넘버링 — 점검 위치를 1클릭, 번호가 표시될 자리를 2클릭.
  3. 사진 폴더 연결 — 현장 사진 폴더를 지정하면 파일명 끝 숫자로 자동 매칭됩니다.
  4. 내보내기 — 도곽을 채우고 PDF로 저장합니다.

사진 파일명 → 번호 매칭 규칙

사진 폴더를 연결하면 파일명 뒤쪽 숫자를 읽어 같은 번호의 넘버링과 자동으로 짝지어 줍니다.

파일명 예시매칭되는 번호
현장001.jpg1번
DSC_042.jpg42번

층별 접두어를 쓰는 경우(예: 1F) 파일명도 101.jpg처럼 층+번호 3자리 코드로 맞춰야 정확히 매칭됩니다. "파일명 일괄 변경" 기능이 이 변환을 자동으로 해 줍니다. 매칭이 안 맞으면 사진 탭에서 매칭 번호를 직접 입력할 수 있고, 매칭된 항목은 목록에서 파일명이 함께 표시됩니다.

저장 · 내보내기

  • 작업 중 변경사항은 자동으로 저장됩니다(저장 상태 인디케이터로 확인).
  • 내보내기는 PDF로 하며, 불러온 도면·넘버링·도곽(표제란)을 A4 규격에 맞춰 합성합니다.
  • 여러 페이지 작업 시 페이지 수만큼 PDF에 그대로 담깁니다.
  • 체험판에서는 PDF 저장이 현재 활성 페이지 1장으로 제한되고, 워터마크가 표시됩니다. 도면 불러오기·페이지 추가·프로젝트 파일 복원 자체는 제한이 없습니다.
  • 사진첩(외관집계표 대조) 기능이 있는 경우, 대조 결과를 6칸 격자 A4 사진첩으로 PDF 출력할 수 있습니다. 체험판은 사진첩도 1장·워터마크 제한이 있습니다.

자주 묻는 질문

  • 인터넷이 안 되는 현장에서도 쓸 수 있나요? — 됩니다. 정품 인증은 최초 1회만 인터넷이 필요하고, 이후에는 인터넷 없이 사용합니다.
  • 사진 폴더가 안 열려요. — 사진 폴더 연결 기능은 Chrome/Edge 브라우저 기반 화면에서만 동작합니다. Firefox에서는 지원하지 않습니다.
  • PC를 바꾸면 어떻게 하나요? — 기존 PC의 등록을 반납 처리하면 새 PC에서 다시 인증할 수 있습니다. (메일 문의)
  • 도면을 여러 장 불러오면 번호가 이어지나요? — 페이지별로 넘버링이 독립적으로 저장됩니다. 페이지를 바꿔도 이전 작업은 그대로 유지됩니다.
  • 번호를 하나 지우면 뒷번호가 자동으로 당겨지나요? — 네. 삭제 시 번호가 재정렬되며, 좌표 등 나머지 정보는 유지됩니다.
