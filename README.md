# NumDraw — 시설물 안전점검 도면 넘버링 툴

건축 시설물 안전점검 결과보고서 작성 시 필요한 **도면 넘버링 작업**을 웹 브라우저에서 빠르게 수행하는 툴입니다.

---

## 실행 방법

`index.html` 파일을 **Chrome 또는 Edge** 브라우저에서 직접 열어 실행합니다.  
서버나 설치 불필요.

---

## 주요 기능

### 도면 불러오기
- PDF (다중 페이지), JPG, PNG 등 이미지 파일 지원
- 파일 선택 버튼 또는 **드래그&드롭**으로 불러오기
- 불러온 도면은 A4 규격(150dpi)으로 자동 변환

### 넘버링 추가 (2클릭)
1. **1클릭** — 도면에서 점검 위치 지정 (지시점)
2. **2클릭** — 번호 박스 위치 지정

### 다중 페이지 관리
- 좌측 페이지 패널에서 페이지 추가 / 삭제 / 이름 변경
- 페이지별 넘버링 독립 저장
- **페이지별 접두어 설정** — 1F, 2F, RF 등 층별 구분 가능

### 카테고리
| 구분 | 색상 |
|------|------|
| 결함 | 빨강 |
| 보수 | 파랑 |
| 기타 | 보라 |

각 카테고리 색상은 자유롭게 변경 가능합니다.

### 사진 연동 및 파일명 변경
1. **사이드바 → 사진 탭** 에서 폴더 선택
2. 사이드바 넘버링 목록에서 사진 매칭 번호 직접 입력 (Tab 키로 순차 이동)
3. **변환 미리보기** 버튼으로 변경될 파일명 확인
4. **파일명 일괄 변경** 버튼으로 일괄 적용

> 접두어 변환 규칙: `1F-01 → 101`, `2F-02 → 202`, `RF-01 → R101`, `B1F-03 → B103`

### 도곽 (표제란)
- 툴바 **도곽 설정** 버튼으로 프로젝트명, 도면명, 축척 입력
- 도면명은 페이지별로 독립 저장
- 도곽 ON/OFF, 크기 배율 조절 가능

### PDF 내보내기
- 툴바 **PDF 저장** 버튼
- 모든 페이지의 넘버링 + 도곽이 합성된 PDF 생성

## 단축키

| 키 | 기능 |
|----|------|
| `ESC` | 현재 그리기 취소 |
| `Ctrl+Z` | 마지막 넘버링 되돌리기 |
| `Q` | 직교모드 ON/OFF (수평·수직 고정) |
| `R` | 화살표 방향 반전 |
| `W` | 지시선 스타일 순환 (직선 → ㄱ자 → ㄴ자 → 번개) |
| `F5` | 도면 전체 화면 맞추기 |
| `Shift + 휠` | 넘버링 크기 배율 조절 |
| `Tab` | 사진번호 입력칸 순차 이동 |

### 화면 조작
| 조작 | 기능 |
|------|------|
| 마우스 휠 | 확대 / 축소 |
| 우클릭 드래그 | 화면 이동 (팬) |
| Alt + 드래그 | 화면 이동 (팬) |

## 사이드바 구성

### 넘버링 탭
- 전체 페이지의 넘버링 통합 목록 표시
- **결함번호 / 결함종류 / 매칭번호** 열 구성
- 항목 클릭으로 선택, ✕ 버튼으로 삭제

### 설정 탭
- 접두어 입력 (페이지별 독립 저장)
- 시작 번호, 선 두께, 글씨 색상 설정
- 넘버링 크기 배율 슬라이더

### 사진 탭
- 폴더 선택으로 사진 연동
- 변환 미리보기 / 파일명 일괄 변경

## 지원 환경

| 항목 | 내용 |
|------|------|
| 브라우저 | Chrome / Edge (최신 버전 권장) |
| 사진 폴더 연동 | File System Access API 필요 (Firefox 미지원) |
| 오프라인 | PDF.js CDN 필요 (PDF 불러오기 시 인터넷 연결 필요) |
