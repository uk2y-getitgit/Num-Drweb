# 보관 문서 (archive)

개발·의사결정이 끝나 루트에서 내린 문서들이다. 지우지 않은 이유는 아래와 같다.

| 파일 | 왜 남겨 두나 |
|---|---|
| `유료화_Phase1_구현계획.md` | 라이선스 키 포맷·증서 payload·D1 스키마·활성화 API 계약의 **원본 스펙**. `server/src/` 주석이 이 문서의 장 번호를 가리킨다. 서버를 손볼 때 필요 |
| `사진첩_기능_개발계획.md` | 사진첩 배치 규칙(6칸·행 순서·둘째 줄 줄바꿈 규칙)의 근거. 렌더 결과가 이상할 때 기준값 확인용 |
| `유료화_호스팅_비교안.md` | Cloudflare 를 고른 근거. 인프라를 다시 검토할 때만 필요 |
| `NumDraw_홍보자료.html` | 초기 홍보 페이지 초안. 현재는 `web/product.html` 이 대체함 |
| `agents-legacy/` | 초기 개발용 3에이전트(플래너·코더·리뷰어) 정의. 현재 운영 체계로 대체됨 |

`유료화_작업재개_인수인계.md`(현재 상태), `유료화_배포_따라하기.md`(배포 절차),
