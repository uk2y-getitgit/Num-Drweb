# NumDraw 에이전트 시스템 가이드

## 에이전트 구성

```
사용자(승인자)
     ↕ 보고 / 피드백
┌─────────────────┐
│  Agent 1        │ ← 작업순서 플래너
│  (Planner)      │   진행상황 추적, 단계 허가
└────────┬────────┘
         │ 작업 지시
┌────────▼────────┐
│  Agent 2        │ ← 코드 작성자
│  (Coder)        │   실제 파일 수정/작성
└────────┬────────┘
         │ 완료 보고
┌────────▼────────┐
│  Agent 3        │ ← 승인자 (리뷰어)
│  (Reviewer)     │   코드/UI 검토
└────────┬────────┘
    승인 │ 반려
    ↓    └→ Agent 1 재요청
  Agent 1 → 다음 단계
```

## 작업 흐름

1. **Agent 1** 이 현재 작업 단계를 사용자에게 보고
2. **사용자** 승인 후 Agent 2에게 작업 허가
3. **Agent 2** 코드 작성 완료 → Agent 3에게 보고
4. **Agent 3** 검토 후:
   - 승인 → Agent 1에게 알림 → 다음 단계로
   - 반려 → Agent 1에게 문제점 전달 → Agent 2 재작업

|------|------|------|
