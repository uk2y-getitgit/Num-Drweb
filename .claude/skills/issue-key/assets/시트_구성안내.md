# 구글 시트 대장 만들기 (10분)

거래·문의 원장을 구글 시트에 만든다. Cloudflare D1 은 키와 좌석만 알고,
**누가 얼마를 입금했고 메일을 보냈는지는 아무 데도 기록되지 않는다.** 그 자리가 이 시트다.

## 1. 시트 만들기

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만들고 이름을 **`NumDraw 운영대장`** 으로 한다.
2. 하단 시트 탭 이름을 `거래` 로 바꾼다. `+` 로 시트를 하나 더 만들어 `문의` 로 한다.
3. 각 시트에서 **파일 → 가져오기 → 업로드** 로 아래 파일을 넣는다.
   - `거래` 탭 ← `거래대장.csv`
   - `문의` 탭 ← `문의대장.csv`
   - 가져오기 위치는 **"현재 시트 바꾸기"**, 구분자는 **쉼표**.
4. 예시 행(2행)은 내용을 확인한 뒤 지운다.

## 2. 첫 행 고정 + 필터

`보기 → 고정 → 행 1개`, 그리고 `데이터 → 필터 만들기`.
거래가 쌓이면 상태별로 걸러 보는 일이 잦다.

## 3. 열 규칙

**거래 시트**

| 열 | 규칙 |
|---|---|
| 라이선스키(마스킹) | `ND2-JS9M3-****-****-0T3A9` 형태로만. **전체 키를 적지 않는다** |
| 상태 | `정상` / `정지` / `환불` / `베타` |
| 활성화 좌석수 | `/admin/list` 에서 확인한 실제 값 (0~2) |
| 금액 | 숫자만 (원 단위) |

**문의 시트**

| 열 | 규칙 |
|---|---|
| 채널 | `메일` / `카페` / `단톡` / `전화` |
| 분류 | `사용법` / `오류` / `구매` / `환불` / `기능요청` |
| 재발방지 조치 | 가이드·FAQ 를 고쳤으면 그 사실을 적는다 |

## 4. 왜 전체 키를 안 적나

시트는 브라우저에 로그인만 되면 열린다. 공유 실수 한 번이면 유효한 키가 그대로 새고,
그 키는 이미 고객에게 나간 것이라 **정지 말고는 손쓸 방법이 없다.**
전체 키는 발급 화면과 고객 메일함에만 있으면 충분하다.

## 5. 백업

`파일 → 다운로드 → .xlsx` 를 분기에 한 번. 구글 계정 사고가 나도 대장은 남는다.
받은 파일은 저장소가 아니라 개인 보관 폴더에 둔다 (`.gitignore` 대상).
