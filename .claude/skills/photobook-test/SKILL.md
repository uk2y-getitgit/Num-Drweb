# 사진첩 기능 테스트

`js/photoBook.js` + `app.js` 사진첩 섹션을 검증한다.

## 1. 테스트 데이터 생성

```bash
python .claude/skills/photobook-test/make_fixture.py
```

`AI활용\Quickspect_테스트데이터\` 에 생성된다.

| 산출물 | 내용 |
|--------|------|
| `외관집계표_테스트.xlsx` | 40건. 1~3행 머리글, 4행부터 데이터, **P열에 문구** |
| `사진\` | 37장. `R01~R05`, `201~215`, `101~113`, `B101~B104`, `W01~W03` |

**의도적으로 어긋나게 만든 부분** (경고 팝업 확인용):

- 사진 없음 3건 — `205`, `110`, `B103` 파일을 만들지 않는다
- 문구에 `(신규)` 접두어와 `(보수완료)` 가 섞여 들어간다 (서식 확인용)

층 순서는 실무 그대로 **옥상층 → 지상2층 → 지상1층 → 지하1층 → 외부**.

## 2. 자동 검증 (Node)

```bash
node .claude/skills/photobook-test/test_logic.mjs      # 파싱·역변환·3자 대조·레이아웃
node .claude/skills/photobook-test/test_render.mjs     # renderPage 호출 경로·좌표·메모리 해제
node .claude/skills/photobook-test/test_caption.mjs    # 문구 줄바꿈 규칙 5종
node .claude/skills/photobook-test/test_imgscale.mjs   # 도면 배율 ↔ 넘버링 좌표 동기화
node .claude/skills/photobook-test/test_bounds.mjs     # 작업범위 안내선 + Ctrl/Shift+휠 분기
```

통과 기준:

- 층키 역변환 9/9 (`옥상층→RF`, `지상10층→10F`, `지하1층→B1F`, `외부→W`, `1층→1F` 포함)
- 집계표 40건 파싱, `captionCol: "P"`, 순서 `RF → 2F → 1F → B1F → W`
- 사진 없음이 정확히 `2F-05, 1F-10, B1F-03` 3건
- 사진칸 비율 **1.017** (엑셀 실측값과 일치해야 한다)
- 페이지당 테두리 = `1 + 칸수 × 3`, `drawImage` 수 = `bitmap.close` 수 (누수 없음)
- 모든 도형이 A4(1240×1754) 안에 있을 것
- 문구 줄바꿈 5/5 — 치수가 있으면 치수 앞에서, 없으면 `(보수완료)` 앞에서 줄을 바꾼다
- 도면 배율: 중심 유지 · 넘버링 동반 이동 · 1.0 복귀 시 좌표 왕복 오차 0 · 원본 불변
- 안내선: 화면 렌더에는 있고 `createPageExport` 에는 **0건** (PDF 유출 방지의 핵심 검사)
- 휠 분기: 일반=화면 줌 / Shift=넘버링 배율 / Ctrl·Cmd=도면 배율, 셋 다 `preventDefault`

## 3. 브라우저 수동 확인

`index.html` 을 Chrome/Edge로 연다 (File System Access API 필요).

1. 도면 아무거나 불러오기 → 페이지 접두어를 `1F` 등으로 지정하고 넘버링 몇 개 찍기
2. **사진 탭 → 사진 폴더 선택** → `Quickspect_테스트데이터\사진`
3. **사진 탭 → 외관집계표 불러오기** → `외관집계표_테스트.xlsx`
   - `✓ 40건 · 외관집계표 · 문구 P열` 이 초록색으로 뜨는가
4. **사진첩 미리보기**
   - 미매칭 경고 팝업이 먼저 뜨는가 (사진 없음 3건 + 도면 미표기 목록)
   - `그대로 생성` → 7장이 순서대로 렌더되는가

체크할 것:

- [ ] 표제에 도곽 설정의 **Project Title** 이 그대로 나오는가
- [ ] 한 장에 **6칸**(3행 × 2열), 마지막 장만 4칸인가
- [ ] 번호 라벨이 `RF-01`, `2F-01`, `B1F-01`, `W-01` 형태로 맞는가
- [ ] 사진에 찍힌 노란 번호와 라벨이 **일치**하는가 (매칭 검증의 핵심)
- [ ] 층이 바뀌어도 페이지를 가르지 않고 이어지는가
- [ ] 사진이 칸에 **꽉 늘어나** 있는가 (여백 없이 — 엑셀과 동일)
- [ ] `205`, `110`, `B103` 자리에 회색 **"사진 없음"** 이 있는가
- [ ] `(보수완료)` 가 **파란색 굵게**, `(신규)` 는 검정으로 나오는가
- [ ] 긴 문구가 칸 밖으로 넘치지 않고 줄바꿈되는가
- [ ] 콘솔에 에러가 없는가

5. **사진첩 PDF 저장** → 파일이 열리고, 미리보기와 같은지 확인

## 3-b. 도면 배율 수동 확인

상단 컨트롤 바 **도면 N.N×** 슬라이더 / **Ctrl+마우스 휠**.

- [ ] 슬라이더를 움직이면 도면 크기가 바뀌는가
- [ ] **Ctrl+휠**로도 조절되고, 이때 브라우저 화면이 확대되지 않는가
- [ ] 그냥 휠은 화면 줌, Shift+휠은 넘버링 배율로 그대로 동작하는가
- [ ] **작업범위 표시** 체크박스로 점선 테두리가 켜지고 꺼지는가
- [ ] 점선 테두리 바깥을 클릭하면 넘버링이 안 찍히는가 (안내선 = 실제 클릭 경계)
- [ ] 저장한 PDF에 점선 테두리가 **없는가** ← 반드시 확인
- [ ] **넘버링이 도면을 따라 움직이는가** — 지시점이 원래 가리키던 곳을 계속 가리켜야 한다
- [ ] 1.0으로 되돌리면 원래대로 정확히 복귀하는가
- [ ] 확대해서 도면이 용지 밖으로 나가면 경고 메시지가 뜨는가
- [ ] 페이지를 전환했다 돌아와도 배율이 유지되는가
- [ ] 배율을 준 상태로 **도면 PDF 저장** 시 화면과 같은가
- [ ] 반복해서 확대·축소해도 화질이 나빠지지 않는가 (원본에서 매번 다시 합성)

## 4. 라이선스 게이트 확인

체험판 상태에서 저장하면 워터마크가 찍히고 `maxPages` 장까지만 저장되어야 한다
(도면 PDF 저장과 같은 기준). 정품이면 전체 장수가 워터마크 없이 나온다.

## 주의

- 테스트 데이터는 **저장소 밖**(`AI활용\Quickspect_테스트데이터`)에 만든다. 저장소를 더럽히지 않는다.
- `photoBook.js` 의 색상 리터럴은 캔버스 렌더라 CSS 변수를 쓸 수 없다 —
  `no-hardcoded-color` 경고가 떠도 정상이다 (해당 훅의 예외 3번).
