✅ **작업 종료 전 확인사항:**

마지막으로 다음을 체크해주세요:

**기능 관련:**
- [ ] 코드 변경이 구현할 기능의 목적과 부합하는가?
- [ ] 해당 기능에 영향 있는 다른 코드가 수정되지 않았는가?
  - 수정된 경우, 주요 변경사항을 정리했는가?

**품질 확인:**
- [ ] 브라우저에서 기능을 직접 테스트했는가? (UI 변경의 경우)
- [ ] 콘솔 에러가 없는가?
- [ ] 기존 기능에 회귀(regression)가 없는가?

**문서화:**
- [ ] 주석은 필요한 곳에만 추가되었는가?
- [ ] 커밋 메시지는 한국어로 작성되었는가?

모든 항목을 확인했다면 안내를 종료하셔도 좋습니다.
